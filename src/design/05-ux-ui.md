- แถบซ้ายสุด (activity rail): คลัง · เพิ่มด่วน · การเชื่อมต่อ · ⚙ — ไม่เกิน 4 ปุ่ม (UX-LAYOUT)
- แผงกลุ่ม = Tellico Group view: จำนวนต่อกลุ่ม + กลุ่ม "(ว่าง)" → คลิกกรองกลาง · คือทางหา "ข้อมูลที่ต้องซ่อม"
- ตาราง: แถว `row-compact` 28 (ไม่มีรูป) / `row-comfy` 40 (มีรูปปกย่อ) — สองขนาดจาก token · คลิกหัวคอลัมน์ = เรียง
- ตารางเขียนเองด้วย `ListView.builder` + `Row` คอลัมน์กว้างคงที่ (virtualized อยู่แล้ว) —
  `ponytail: ไม่ใช้ grid package; โหมดแก้ตาราง (S11) ค่อยตัดสินใจเรื่อง two_dimensional_scrollables`
- เส้นแบ่งแผงลากได้ (ดับเบิลคลิก = คืนค่า) · `Ctrl+Alt+B` ซ่อนแผงขวา (ตรงกับ DraconDex)
- 800–1200 px: แผงกลุ่มเป็น drawer · < 800 px: หน้าจอมือถือเดิมทั้งชุด (code เดียว — `LayoutBuilder` ใน `home_screen.dart`)

## 4. S5 — เพิ่มด่วนด้วยสแกนเนอร์ USB (keyboard-wedge)

```
┌ เพิ่มด่วน                   โหมด (•) เพิ่มทันที ( ) ให้ตรวจก่อน (v1)   ☑ เสียง ┐
│ ┌──────────────────────────────────────────────────────────────────┐ │
│ │ ▌ยิงบาร์โค้ดได้เลย…                              ● พร้อมรับ (โฟกัสอยู่) │ │
│ └──────────────────────────────────────────────────────────────────┘ │
│ ✓ 978404… Overlord 3        เพิ่มแล้ว                       [เลิกทำ]  │
│ ⟳ 978404… กำลังค้นข้อมูล…                                              │
│ ⚠ 978404… Overlord 4        มีอยู่แล้ว   [ข้าม] [เพิ่มเป็นอีกเล่ม]       │
│ ✕ 978616…                   ไม่พบข้อมูล  [กรอกเอง…] [ลองใหม่]          │
│ ⓘ 885123…                   ไม่ใช่ ISBN (บาร์โค้ดสินค้า)                │
│ รอบนี้: เพิ่ม 1 · ซ้ำ 1 · ไม่พบ 1 · ผิด 1          [เลิกทำทั้งรอบ (1)]   │
└──────────────────────────────────────────────────────────────────────┘
```

1. ยิง → ภายใน ≤ 200 ms ขึ้นแถวพร้อมผลตรวจ checksum (`isbn_utils`) · ค้น metadata แบบ async ตามลำดับ provider เดิม · ไม่บล็อกการยิงครั้งถัดไป
2. ผลบอก 3 ทาง: ไอคอน + ข้อความ + เสียง (ปิดได้) — ไม่ใช้เสียงหรือสีอย่างเดียว
3. โฟกัสหลุด → แถบ "โฟกัสหลุด — คลิกหรือกด F6" · หน้าต่างกลับมา active = คืนโฟกัสเอง (ปัญหาอันดับ 1 ของ wedge scanner)
4. ตัวจับพิมพ์รัวในช่องค้นหาหลัก: ≥ 10 ตัวที่ห่างกัน < 50 ms + Enter → ส่งเข้าเพิ่มด่วน — **ค่าเกณฑ์ปรับได้ใน S8** (ต้องวัดกับเครื่องจริง ❓ Q7)

## 5. S4 — แก้หลายเล่ม + พรีวิว diff (ใช้ซ้ำกับ Z.I.Z)

```
┌ แก้ 3 เล่มพร้อมกัน ─────────────────────────────────────── ✕ ┐
│ ผู้แต่ง      [(หลายค่า) Maruyama · — ▾]   ☐ เขียนทับทุกเล่ม       │
│ ซีรีส์       [Overlord                ]   ☑ เขียนทับทุกเล่ม       │
│ สถานะ        [(ไม่เปลี่ยน) ▾]  วันที่ [วันนี้]                     │
│ หมวด         (•) เพิ่ม ( ) ลบ   [Light Novel ×][+]               │
│ หา/แทนที่    ในช่อง [สำนักพิมพ์ ▾] [Kadokawa] → [KADOKAWA]       │
│              แนะนำ: เพิ่ม "Kadokawa ↔ KADOKAWA" เป็นชุดชื่อแทน?  │
│ ┌ ผลที่จะเกิด: 3 เล่ม · 5 ช่อง ───────────────────────────────┐ │
│ │ Overlord 3  สำนักพิมพ์  Kadokawa → KADOKAWA                │ │
│ │ Overlord 3  ซีรีส์       (ว่าง) → Overlord                 │ │
│ │ …                                                          │ │
│ └────────────────────────────────────────────────────────────┘ │
│ [ยกเลิก]                                     [ใช้กับ 3 เล่ม]   │
└──────────────────────────────────────────────────────────────┘
```

- ค่าเริ่มต้นทุกช่อง = **(ไม่เปลี่ยน)** · ช่องที่ค่าต่างกันแสดง **(หลายค่า)** เป็นข้อความ (ไม่ใช่แค่ตัวเอียงสีจาง) และต้องติ๊ก "เขียนทับ" เอง
- พรีวิวคำนวณจาก `diff()` (04 §6) ทุกครั้งที่แก้ช่อง · ปุ่มหลักบอกจำนวนเล่มเสมอ · หลังใช้: toast "แก้ 3 เล่มแล้ว [เลิกทำ]"
- ≥ 1200 px เป็นแผงขวา (แทนรายละเอียด) · แคบกว่านั้นเป็น modal `md`
- **โหมดรีวิวข้อเสนอ Z.I.Z:** หัวเป็น "Z.I.Z เสนอแก้ 42 เล่ม" + ป้าย client · ช่องแก้ไขเป็นอ่านอย่างเดียว · ติ๊กออกรายเล่มได้ ·
  ปุ่ม `[ปฏิเสธ] [ใช้ที่เลือก (40)]` — ใช้แล้วมี "ย้อนการเปลี่ยนแปลงจาก AI ครั้งนี้" (snapshot, ECO-S3)

## 7. Flow หลัก

**F-A เริ่มใช้ครั้งแรกบน PC (S9)**
1. หน้าต้อนรับ: `[เริ่มคลังใหม่]` `[นำเข้าจากมือถือ…]` (`.zeco` หรือ `.zip`) — คำอธิบายสั้นว่าส่งออกจากมือถือที่ Settings → สำรองข้อมูล
2. นำเข้า → S6 พรีวิว → ยืนยัน
3. (ไม่บังคับ) "ทดสอบสแกนเนอร์": ยิงบาร์โค้ดหนังสือ 1 เล่ม → ✓ ทำงาน / ✕ ลิงก์ help ตั้งค่า HID + Enter
4. เข้า S1

**F-B ย้ายข้อมูลมือถือ ↔ PC** — ส่งออก `.zeco` ที่เครื่องต้นทาง → ส่งไฟล์เอง (สาย/คลาวด์/LINE) → ลากใส่หน้าต่าง PC → S6 พรีวิว:

**F-C ให้ Z.I.Z ช่วย** (T4-C §4.5)
1. เลือกเล่ม → `[เปิดใน Z.I.Z ▾]` → "เติมข้อมูลที่ขาด" / "หาเล่มซ้ำ/ชื่อสะกดต่าง" / "สรุปคลัง" / "พิมพ์คำสั่งเอง…"

## 8. Accessibility

- ตาราง: `Semantics` ต่อแถว (เลือกแล้ว/ยัง, ลำดับเรียง) · ลูกศรเลื่อนแถว · `Space` เลือก · หัวคอลัมน์เป็นปุ่มที่บอกทิศการเรียง · ประกาศ "เลือก 3 จาก 148"
- ชั้นสัน (ตัวอักษรหมุน) อ่านด้วย screen reader ไม่ได้ → เป็นแค่มุมมองของรายการเดียวกัน + `Semantics(label: 'ชื่อ, ผู้แต่ง')` ต่อสัน
- รูปปกมี label = ชื่อเรื่อง · ผลสแกนประกาศผ่าน live region ("เพิ่ม Overlord 3 แล้ว")
- เป้าคลิก desktop ≥ 28 (ไอคอน) / 32 (ปุ่มข้อความ) — แถว 28 ผ่าน WCAG 2.5.8 (24 px)
- โฟกัสริง 2 px (`focus-ring` token) ไม่ถูกบัง (WCAG 2.4.11) · เคารพ `MediaQuery.disableAnimations`
- ทดสอบกับ Narrator/NVDA: ❓ ระดับ Eco (T4-C §8 ข้อ 15) — ไม่ได้ถามซ้ำที่นี่
