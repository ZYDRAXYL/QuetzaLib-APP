## 5. ที่ตั้งใจไม่ทำ

| ไม่ทำ | เหตุผล |

| multi-window | Flutter desktop multi-window ยังไม่เสถียร (T4-C §7) และไม่จำเป็น |
| MCP แบบ HTTP | ECO-C1 #7 เลื่อนไป v2 · ECO-S7 |
| live sync กับแอปอื่น | ECO-C1 #9 |
| macOS / Linux | Eco v1 = Windows เท่านั้น — Flutter ทำได้ภายหลังโดยแทบไม่แตะ `lib/` |
